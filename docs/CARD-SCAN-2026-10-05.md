# Card and alternate artwork update — 5 October 2026

This records the local card audit and validation. It was subsequently included in the [5 October website release](./WEB-RELEASE-2026-10-05.md). The pre-existing `next-env.d.ts` change was preserved.

The desktop audit checked Piltover Archive's complete catalog and Riot's card gallery, verified artwork responses, and inspected printed identities. The finalized source is `../recording-sharing-refresh-desktop/resources/riftbound_card_registry.json` plus its companion overlay. Source evidence and the exact 66 additions are in `../recording-sharing-refresh-desktop/output/card-scan-20261005/`, including `normalized-additions.json` and `final-art-http-evidence.json`. Placeholder art and invented source identifiers were excluded.

## Website changes

- The Radiance replay catalog increases from 110 to **150 prints**, and the compact training registry from 1,299 to **1,365**. Metadata and artwork match the desktop registry exactly.
- Evelynn, Agony's Embrace is available as a legend; Black Rose Sanctum and Firelights' Hideout are recognized battlefields. Signed Mordekaiser, alternate Evelynn and alternate Packed Amphitheater retain their exact printed artwork. Name-only battlefield captures continue to use their ordinary printing.
- Hunters' Circle uses its printed spelling. Captures using the previous Hunter's Circle spelling still resolve through the existing normalized name lookup.
- `audited-print-art.json` provides exact fallback art for **26 additional historical/promotional prints**, including Arcane cards, older alternate runes and tokens. It also retains **280 alternate image URLs across 252 prints**, including previously supported aliases. Audited captured art survives image-resizing query parameters, while existing canonical artwork remains unchanged.
- The legacy replay parser now preserves signature, rune, promo and token collector identities, including encoded `*` and `-star` spellings. It previously reduced signed identities such as `RAD-168*` to the unsigned print.
- TCGA normalization already consumes public `cardData.id` values rather than an image-hash lookup. New tests confirm the new legend, signed legend, alternate legend and Arcane identifiers survive normalization and its privacy checks. Image-hash recognition remains in the desktop capture registry.

## Validation

- Full website suite: **1,445 passed, 9 skipped** across 172 passing test files and one skipped file.
- After adding explicit old-spelling, alternate-battlefield and TCGA print checks: the five card/legend suites passed **112 tests** and the TCGA suite passed **37 tests**.
- TypeScript: `npx tsc --noEmit --incremental false` passed.
- Changed source files passed ESLint. All application source has zero lint errors (14 existing warnings). Broader lint also inspects ignored generated output and the unchanged `scripts/opening-lab/preview.cjs`, which has three existing CommonJS import errors; no unrelated lint configuration or scripts were changed.
- `output/card-scan-20261005/website-parity.json` confirms every compact registry field, Radiance print/art, newly added historical artwork and image alias matches the finalized desktop catalog. Supporting sync and parity scripts are saved beside that receipt.

No live replay records, capture data or user profiles were changed.
